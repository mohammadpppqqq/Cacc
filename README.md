# Light Calculator

A simple Android calculator built with Python and Kivy.

## Features

- Light theme
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Parentheses
- Decimal numbers
- Clear button
- Backspace button
- Android APK build through GitHub Actions
